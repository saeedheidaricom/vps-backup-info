Saeed VPS Backup · Privacy

Privacy statement

This statement covers Saeed VPS Backup, a private, single-user integration operated by the owner of the connected Google account. It describes the intended configuration while setup is in progress; automated backups have not yet been enabled.

Information and permissions

The Google Drive permission requested is https://www.googleapis.com/auth/drive.file. The integration uses it to create, list, read, update and delete its authorized backup repository files, including metadata required for backup, integrity checks, retention and restore. It does not request general access to all existing Drive documents, Gmail, contacts or calendars.

Google issues OAuth credentials after the owner grants consent. Those credentials allow the VPS to connect automatically. They will be stored in a file with restricted permissions on the VPS and excluded from the source-code repository and public website. Google sign-in occurs with Google; the integration does not collect the owner's Google password.

Backup contents and use

The owner chooses which VPS files are included. Before backup is enabled, restic will be configured to encrypt backup contents locally before uploading them to Google Drive. The owner will keep a separate recovery copy of the encryption password outside the VPS.

The integration uses authorized Drive data for backup creation, repository maintenance, integrity checks and restoration. It does not use that data for advertising or sell it. Backup data remains in the owner's Google Drive unless the owner deliberately copies, shares or removes it.

Providers and this website

The VPS provider hosts the source system; Google Drive stores the backup repository. These providers process information under their own service terms and privacy policies.

This information website contains no sign-in form, analytics script or tracking cookie set by the site itself. When hosted on GitHub Pages, GitHub logs visitor IP addresses for security purposes under its privacy statement. Visiting this site does not grant access to Google Drive.

Retention and deletion

The account owner controls backup retention. Once enabled, stored backup files can remain until removed through the backup retention process or deleted from Google Drive. Removal of an individual source file does not necessarily remove older backup snapshots containing it.

Revoking access and recovery

The owner can revoke the integration's access through the third-party connections settings of the Google Account. Revocation stops future authenticated access; existing backup files must be removed separately if deletion is desired.

Restoring encrypted backups requires access to the backup repository and the encryption password. Losing that password can prevent recovery.

Contact and changes

For questions or a data request, use the support email displayed on the Saeed VPS Backup Google consent screen. This statement will be updated when the workflow or data handling changes.
